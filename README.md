# Lung Cancer CT Classification

A Streamlit web app that classifies lung CT scans as Benign, Malignant or Normal using a fine-tuned ResNet50 model.

**Live app:** https://lung-cancer-ct-classification-hkvvptrpg9jy8bbxegakk7.streamlit.app/

## How it works

1. Upload a CT image (JPG, JPEG or PNG).
2. Click Predict.
3. The app shows the predicted class, confidence and class probabilities.

## Tech used

- Python, TensorFlow / Keras (ResNet50)
- Streamlit (app and hosting)
- Hugging Face (model storage)

## Disclaimer

This project is for academic and research purposes only. It does not provide a medical diagnosis and must not be used for clinical decisions.
